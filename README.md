# Mohammed Yasar Shajahan: portfolio website

Static site (no build step). Files: index.html, images, resume.pdf, logo files.

## Option A: Netlify (free, about 1 minute)
1. Go to https://app.netlify.com/drop and sign in (free).
2. Drag this whole folder (mys-portfolio) onto the page.
3. Open Site configuration > Change site name and type the name you want,
   for example `yasar`. The address becomes https://yasar.netlify.app
   If the name is taken, try `mohammedyasar` or `yasar-shajahan`.

## Option B: GitHub Pages (free)
1. Create a GitHub account. For https://yasar.github.io your GitHub username
   must be exactly `yasar`. If it is taken, use your own username
   (the address becomes https://YOURUSERNAME.github.io).
2. Create a public repository named `YOURUSERNAME.github.io`.
3. Upload every file in this folder to the repository root (Add file > Upload files).
4. Open Settings > Pages, set Source to "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
5. Wait a minute, then open https://YOURUSERNAME.github.io

## Resume
The "View resume" button opens an in-page resume. "Download PDF" uses resume.pdf:
replace it with your latest file (keep the same name) and upload again.
